## 1. Verified public interface

### Facts (read from public code)

**I/O.** Vocab = 17: `{PAD,BOS,N,X,T,ANS,EOS}` + digits 0–9 (`DIGIT_OFFSET=7`). All current datasets use `separate_input_output=True`: the prompt is

```
[N] d(N)… [X] d(x)… [T] d(T)…        (base-10, MSB first)
```

and the label is the digit string `d(y)`, **tail-aligned**: `target_positions = arange(input_len − |d(y)|, input_len)` (`squaring_mod.py::collate_squaring_mod`). The model is called **once** per batch — `logits, aux = model(input_ids, attention_mask=…)` — must return logits of shape `(B, S, 17)`, and the evaluator reads `logits[b, target_positions[b]]` (`runner.py` ~L228–310). There is **no autoregressive generation loop**; decoding is a single-forward argmax per target slot. Attention may be fully bidirectional (dataset names say "bidirectional"; the runner imposes no causality).

**Supervision.** Default loss = token CE over valid tail slots. A participant may supply `token_training_loss(TokenLossBatch)` receiving `logits, labels, valid_mask, target_positions, auxiliary` — where `auxiliary` is **whatever second output the model returns**. Exact-row = every target token argmax-correct. The evaluator owns backward; participants may request ≤8 evaluator-owned backward passes per update and bounded batch reuse via `should_reuse_batch(BatchReuseContext)`.

**Recurrence/scoring.** Every dataset carries evaluator-only splits `depth_t_{1,2,4,8,16,32,64}` and `depth_ood_n_t_*` at modulus bit-sizes disjoint from training. Certification is a **consecutive prefix starting at T=1**: `_evaluate_depth_profile` sets `prefix_solved=False` forever after the first non-perfect rung. Labels are generated by the trapdoor `pow(x, 2^T mod φ(N), N)`; `x` is always sampled coprime to `N`.

**Training depths.** Public tiers: E1 `T∈{1,2,3}`, E2 `{1,2,4}`, E3/E4 fixed `T=2`, E5 `{1,2,3}`; M1/M2 `T∈{4,8,16}`, M3 `T=2`, M4 `T=8`, M5 `{2,4,8}`. The Hard manifest (`h1`) is **not public** (hosted-only). Site: "Hard … may change aspects of the recurrence itself; do not assume it is repeated squaring."

**Legality.** Rules 6–9, 14: random init, no hard-coded algorithm in forward, unbroken autograd path, GPU-only, no participant `backward`, no data inspection/augmentation, no task-specific solvers. README explicitly: "recurrence, tied weights, iterative refinement, routing, adaptive halting, memory tokens, and **parameter-free work** are all valid."

### Deductions

- **T=1 is the whole leaderboard gate.** Since certification is a prefix from T=1, a model that is perfect at T∈{2,…,64} but imperfect at T=1 scores `max_certified = 0`. Your 0/768+0/768 caps the score at rung-0 regardless of anything else.
- **Your run's CE localizes the failure.** Uniform guessing over the 10 digit tokens gives CE = ln 10 = 2.3026. Observed CE 2.17846 ⇒ mean true-digit probability e^{−2.178} ≈ 0.1132, i.e. ~13% above chance per digit. Expected exact-row rate on 5-digit answers ≈ 0.1132⁵ ≈ 1.9·10⁻⁵ ⇒ E[hits in 768] ≈ 0.015. **0/768 is exactly what a barely-above-chance model produces.** So the observed failure is an *optimization/representation* failure, not (yet) evidence of the identifiability failure analyzed next — but the identifiability failure is waiting behind it if Hard's depth set omits T=1.
- 768 = the depth-cohort size pattern used in M2 (`depth_evaluation_examples_per_setting 768`), consistent with Hard using 768-example rungs.

### Assumptions
- Hard `h1` is the same `squaring_mod` family with `split_group="modulus"` (seen vs unseen modulus identities), larger bit-sizes, and a training depth set plausibly like `{4,8,16}` (Medium's pattern) — i.e. **possibly omitting T=1 and possibly all even**.

### Speculation
- "May alter the recurrence" suggests the hidden transition might be e.g. `x_{t+1} = a·x_t² + b` or `x_t·x` mod N — reason to learn a *generic binary register operation*, not squaring-specific wiring.

## 2. Identifiability when training depths omit T=1

Work on the unit group G = (ℤ/N)^×, |G| = φ(N), exponent λ(N) = lcm(p−1, q−1). Let f(x) = x² mod N, and let 𝒯 be the training depth set. Training data constrains only the composites f^{∘T}, T∈𝒯, and — since T is a *prompt token* — not even that: the loss factorizes over depths, so absent architectural weight-tying, the per-depth maps g_T are **completely independent**. A "one-step map" exists only if the architecture ties it. Assume the strongest favorable case: a weight-tied step h iterated T times. Even then:

**Theorem 1 (even-depth non-identifiability).** Let h(x) := (x²)^{−1} mod N (inverse of the square; well-defined on G, uniformly computable from digits of N, x). Then for every N = pq and every **even** T:
$$h^{\circ T}(x) = x^{(-2)^T \bmod \lambda(N)} = x^{2^T} = f^{\circ T}(x) \quad \forall x \in G,$$
because (−2)^T = 2^T for even T. Yet at T=1, h(x) = f(x) ⟺ x⁴ ≡ 1 (mod N), which has exactly gcd(4,p−1)·gcd(4,q−1) ≤ 16 solutions. So h agrees with f on **every** training example of every even depth and every modulus (seen or OOD), and disagrees with f on ≥ φ(N) − 16 of the T=1 inputs. ∎

A weight-tied model that has *perfectly* internalized modular arithmetic can therefore certify T=2,…,64 and still score ≈0/768 at T=1. The T=1 rung is precisely the parity probe that separates h from f.

**Theorem 2 (ambiguity family; g = gcd 𝒯).** For any ζ with ζ^g ≡ 1 (mod λ(N)), define h_ζ(x) = x^{2ζ mod λ(N)}. Then for all T ∈ 𝒯 (each a multiple of g in e.g. 𝒯={4,8,16}, g=4):
$$h_\zeta^{\circ T}(x) = x^{(2\zeta)^T} = x^{2^T \zeta^T} = x^{2^T} \quad (\zeta^T \equiv 1 \bmod \lambda(N)).$$
The number of such ζ is $\prod_{r^a \| \lambda(N)} \#\{\zeta \bmod r^a : \zeta^g \equiv 1\} \ge 2^{\omega_{odd}(\lambda(N))}$ when g is even — exponential in the number of prime factors of λ(N). Beyond exponent maps, *any* functional g-th root of f^{∘g} on G's functional graph is admissible; these are superexponentially numerous. ∎

**Corollary.** The training objective identifies f at T=1 iff extra structure is imposed. Within exponent maps, adding **any odd depth** to 𝒯 (in particular T=1: k ≡ 2 mod λ(N) across many N forces k = 2) collapses the family. Participants cannot add data (Rule 14). So the resolution must be an **architectural inductive bias** — constructed and proven in §3.

## 3. The T=1 mechanism: what must be learned, and what uniquely pins it down

### 3.1 Why ordinary token regression fails

**Lemma (no transfer for lookup classes).** Any hypothesis class closed under independent modification of the map for each modulus value (which includes "embed N as an opaque symbol and regress digits") satisfies: training on moduli 𝒩_train places **zero constraint** on behavior at N ∉ 𝒩_train; expected OOD-N exact accuracy is at chance. Generalization to unseen N requires the hypothesis to be a **program uniform in the digits of N** — every per-N degree of freedom must be eliminated.

**Lemma (flat gradient signal for direct regression).** For prime p | N and additive characters e_p, the Gauss-sum bound |Σ_{x mod p} e_p(ax² + bx)| = √p implies that any fixed output-digit function d_i(x² mod N), decomposed into O(log N) interval indicators, has correlation O(N^{−1/2} log² N) with any function of bounded Fourier complexity in the input digits. At init, the CE gradient w.r.t. any parameter is an expectation of (softmax − onehot(y))·feature; its label-dependent part is bounded by this correlation. For 14–22-bit N this is small (10⁻²–10⁻³), and it **shrinks with N**: a flat regressor's learning signal per step vanishes exactly where Hard lives, while a compositional machine's sub-modules (below) see O(1) signal. (For small N this is soft — direct regression *memorizes* seen N; the killer is the previous lemma: memorization transfers nothing.)

### 3.2 The minimum learnable mechanism

Write x = Σ_{i<L} x_i·10^i. The one legal step decomposes into three digit-local, N-uniform sub-maps:

**(M) Multiply/square (bilinear digit convolution):**
$$c_k = \sum_{i+j=k} \pi(x_i, x_j), \qquad \pi:\{0..9\}^2 \to \{0,\dots,81\} \text{ a 100-entry \emph{learned} table.}$$

**(C) Carry normalization (local scan):**
$$ (r_k, \gamma_{k+1}) = A(c_k + \gamma_k), \qquad A: \text{learned local cell (value} \to \text{digit, carry)}, \gamma_0 = 0.$$

**(R) Reduction by shifted subtraction (long division without quotient output):** for j = W−L_N down to 0:
$$ q_j = \max\{ m \in \{0..9\} : m\cdot N\cdot 10^{j} \le r \}, \qquad r \leftarrow r − q_j\, N\, 10^{j},$$
with q_j selected by a **learned comparator** on aligned digit windows and m·N produced by reusing (M)+(C) on (m, d(N)). Total sequential depth O(L) local operations; every table/cell/comparator is a tiny learned function with O(100) distinct input patterns — trainable from indirect gradients *provided the routing (i+j=k alignment, shift-by-j) is structural*.

**Necessary representation:** the residue must live in a **canonical positional digit register** — a length-W array of (near-)one-hot base-10 slots — for three provable reasons: (i) the label *is* this representation (tail-aligned digit tokens), (ii) sub-maps (M),(C),(R) are local only in this coordinate system, (iii) composition across t requires the step's output manifold to equal its input manifold (closure), which soft distributed codes do not give you for free (§4.4).

### 3.3 The extra legal inductive bias that restores identifiability — with proof

This resolves the underdetermination of §2 exactly, as the prompt demands.

**Structural constraints (all parameter-free routing, explicitly legal per README):**
- **(B1)** The step is z ↦ R(M(z,z), N) with M realized as the bilinear digit convolution above — hence M(z,z), as an integer, is a fixed **quadratic polynomial P(x) with N-independent integer coefficients** (bounded by table range), once training has made the tables integral (ST-rounded).
- **(B2)** R may only subtract digit-multiples m·N·10^j — hence R is **residue-preserving**: R(v, N) ≡ v (mod N).

**Theorem 3 (uniqueness under B1+B2).** Suppose a step of the form (B1)+(B2) satisfies h^{∘T} = f^{∘T} on all units of moduli 𝒩 for some T ∈ 𝒯 (even suffices), where 𝒩 contains moduli exceeding 2^{deg} and jointly exceeding the coefficient bound (true for any Medium/Hard family). Then the step **is exactly** x ↦ x² mod N. In particular the T=1 ambiguity of Theorems 1–2 vanishes.

*Proof.* By (B2), h(x) ≡ P(x) (mod N) with P a single integer quadratic. Then h^{∘T}(x) ≡ P^{∘T}(x) (mod N), so P^{∘T}(x) ≡ x^{2^T} (mod p) for each prime p | N and all x ∈ (ℤ/p)^×. Both sides are polynomials of degree 2^T; for p > 2^T + 1 they agree on more than 2^T points, hence are identical mod p. Coefficients of P are bounded independently of N; taking enough coprime moduli (CRT) forces the **integer** identity P^{∘T}(X) = X^{2^T}. Now conjugate: with φ(X) = X + b/2 (P = aX² + bX + c), leading-coefficient comparison gives a^{2^T−1} = 1 ⇒ a = 1; then P = φ^{−1}∘Q∘φ with Q(X) = X² + c′, and Q^{∘2}(X) = X⁴ + 2c′X² + (c′² + c′) = X⁴ forces c′ = 0, and the shift must vanish; hence P(X) = X². Note the alternative h(x) = x^{−2} of Theorem 1 is **not expressible** under (B1)+(B2): x²·P(x) ≡ 1 (mod N) for all units would make a degree-4 integer polynomial with zero constant term identically 1 — impossible. ∎

So the exact extra legal constraint is: **residue-preserving reduction + N-uniform bounded-degree polynomial multiplier**. Under it, even an all-even training depth set identifies the true one-step map — the inversion-flavored ghosts are excluded from the hypothesis class, not by data.

## 4. A concrete legal architecture: DRM (Digit Register Machine)

~0.5–2M parameters; single forward; everything below is inside autograd on one GPU.

### 4.1 Modules and shapes (B = batch, W = register width from `spec.max_seq_len`, base 10, d_c = 32)

```python
class DRM(nn.Module):
    # persistent state (counts toward cap): all randomly initialized
    #  emb:      (17, 64)  token embeddings (parser keys)
    #  Tab:      (10, 10, d_c)        # digit-pair product table -> (lo,hi) code
    #  hi_lo:    (d_c, 20)            # decode product code to two digit simplexes
    #  Carry:    MLP( 10+C_in -> 10+C_out )  # local add-with-carry cell
    #  Cmp:      MLP( 2*(L_w*10) -> 1 )      # window comparator (>= vs <)
    #  Sub:      MLP( 10+10+B_in -> 10+B_out ) # digit subtract-with-borrow cell
    #  dec:      (10 -> 17) tied linear decoder register->token logits
    #  tau:      buffer(1)  ST temperature; depth_phase: buffer(1)   # gate knobs

    def forward(self, ids, attention_mask=None):
        DN, DX, T_int = parse(ids)          # gather digits after N/X/T markers
        z = onehot_soft(DX)                 # (B, W, 10) canonical register
        for t in range(T_int_max):          # loop count read from prompt digits
            active = (t < T_int)            # per-row adaptive halting (allowed)
            u = square(z)                   # (M): outer prod + anti-diag scatter
            u = carry_scan(u)               # (C): parallel-prefix over W
            z_new = reduce_loop(u, DN)      # (R): W-L_N conditional subtractions
            z_new = st_round(z_new, tau)    # forward: onehot; backward: identity
            z = torch.where(active, z_new, z)
        logits = place_tail(dec(z), ids)    # (B, S, 17); PAD logit elsewhere
        aux = {"z0_logits": dec(z0), "x_ids": x_ids, "ent": entropy(all_z)}
        return logits, aux
```

- `square`: `O = einsum('bip,bjq->bijpq', z, z)` → flatten (B,W,W,100) → `Tab` → scatter-add along the **fixed** binary tensor Δ_{ijk}=[i+j=k] (parameter-free routing, like a causal mask) → (B, 2W, d_c) → `hi_lo` → per-slot value codes.
- `carry_scan`: Blelloch parallel prefix over the `Carry` monoid, depth O(log W) (keeps T=64 eval inside the 1800 s eval budget: ~64·(log W + L·log W) tiny kernels per batch).
- `reduce_loop`: for each shift j: build m·N for m=0..9 by reusing `Tab`+`carry_scan` on (m, DN); `Cmp` scores the 10 candidates; `q_j` = ST-softmax; `Sub` scan subtracts `q_j·N·10^j`. **Only multiples of N are ever subtracted** (B2 holds by wiring).
- Parsing by comparing raw token ids to marker ids, and setting the loop count from the decoded T digits, is input-dependent control flow — adaptive computation, explicitly allowed.

### 4.2 Loss (custom `token_training_loss`) and the scratchpad-code problem

$$\mathcal{L} = \underbrace{\mathrm{CE}(\text{tail logits}, y)}_{\text{only labeled signal}} + \alpha_s\,\underbrace{\mathrm{CE}(\text{dec}(z_0), d(x))}_{\text{input reconstruction}} + \beta_s\,\underbrace{\bar H(z_{1..T})}_{\text{register entropy}}$$

**The final-label-vs-soft-scratchpad conflict, solved in three parts:**
1. **Anchoring**: the reconstruction term uses the *input's own digits* (copied into `aux` by the model — no new data, no augmentation) to force encoder/decoder onto the canonical digit code. Intermediate registers need no labels because —
2. **Closure by construction**: the step consumes and produces the same (W,10) register manifold, and `st_round` (hard forward, identity backward — unbroken autograd path, Rule 8 satisfied) projects every iterate onto the *same vertex set the inputs and outputs live on*. This converts "arbitrary soft hidden codes" into a **finite discrete map** m on registers, reducing all remaining freedom to exactly the combinatorial ambiguity of §2 — which Theorem 3 then kills.
3. **Entropy pressure** β·H keeps the soft phase near the vertices so the ST estimator's bias stays small.

### 4.3 Optimization, curriculum, promotion gates

Evaluator owns data order, so all curriculum is architecture/loss-side; gates are computed from statistics the loss legitimately sees (its own logits/labels), tracked in a closure; knobs are 1-element buffers (count toward cap, trivially).

- AdamW, lr 3·10⁻³ cosine to 3·10⁻⁴, bf16, batch 512, `backward_passes_per_step=1` (extra passes burn clock with no data benefit here).
- **Gate G0→G1** (enable ST rounding, τ: 1→0.3): EMA per-digit accuracy > 0.7. Before this, run fully soft (ST too early kills gradients).
- **Gate G1→G2** (τ→0.1, α_s decay 1→0.1): EMA batch exact-row > 0.9.
- **Gate G2→G3**: EMA exact > 0.995 → switch CE to margin loss on the argmax gap (drives exactness, the only metric that scores); enable `should_reuse_batch` while per-batch loss > θ (bounded reuse is free data-efficiency).
- **Stall fallback**: any gate not reached by its step fraction (25%/55%/80% of `max_steps` estimated from `OptimizerSpec.training_time_seconds`) fires anyway.

Budget check: ~1–2M params, forward cost ≈ T·(W²·100·d_c) ≈ 10⁷–10⁸ FLOPs/example — ≥10⁵ updates in 3600 H100-seconds, far more than your run's 163k updates spent on a mechanism that (per §1's CE arithmetic) never left the chance regime.

## 5. Recurrence — only now

Given §3–4, depth is nearly a corollary, not the problem:

- Because every iterate is ST-projected onto canonical registers, the trained network induces a discrete step m. Certified exactness at the training rungs measured by the evaluator (e.g. T=4 and T=8) means m^{∘4} = f^{∘4} on the evaluated support; Theorem 3 upgrades this to m = (x ↦ x² mod N) on all units of all in-range N. Then all rungs T=16…64 follow **by composition of a map whose exactness has been measured and structurally closed** — no error accumulation channel exists once states are vertex-projected, because there is nothing between vertices for errors to live in. The remaining failure modes are register-width overflow (size W = 2·L_N^{max}+2 from `spec.max_seq_len`) and eval wall-clock (parallel-prefix scans keep T=64 cheap; see §4.1).
- Hard "may alter the recurrence": therefore the step should be wired as a **generic learned binary op** step(z) = R(M(a,b), N) with learned selectors choosing (a,b) ∈ {z, z_prev, x-register, learned constant} — this covers x², c·x², x·x_t, x_t + c-style transitions at the cost of a 4-way learned router, without hard-wiring squaring semantics.

## 6. Red team

**Strongest legality objection.** The Δ_{i+j=k} scatter plus the shift-and-subtract reduce loop is recognizably the *skeleton of schoolbook multiplication and long division*; Rule 7 says "no hard-coded algorithm in the forward pass." Defense: every content-bearing function (product table, carry cell, comparator, subtractor, router) is randomly initialized and learned; the README explicitly blesses "routing … and parameter-free work"; a conv kernel's i−j routing or a causal mask is the same species of structural prior. Residual risk is real: an organizer could rule that the *composition* of these routings constitutes the algorithm. Mitigation: the rules explicitly invite loophole discussion on Discord (`#one-layer-deeper`) — ask before spending the daily Hard attempt; fallback is ranked alternative #2, which keeps canonical registers but learns routing.

**Mathematical counterexample against my own proposal.** Theorem 3's hypotheses bind only **after** training reaches integral tables and exactness at some rung; in the soft pre-G1 regime nothing prevents the same near-chance plateau you observed (CE 2.18). Also, if Hard's altered recurrence is not of the form ρ(polynomial) — e.g. involves a genuinely non-polynomial step like conditional inversion — the (B1)+(B2) class cannot represent it at all, and the bias that saves T=1 identifiability becomes the reason for total failure.

**Fastest falsifier.** Easy tier, 60 s, 60 attempts/day: E1 (N=323, T∈{1,2,3}, exhaustive-x depth cohorts, OOD-N at 10–11 bits) directly scores T=1 seen-N and OOD-N. If DRM cannot certify T=1 on E1 and get >90% OOD-N T=1 on E3 (sampled N, so uniformity is actually tested) within ~10 Easy attempts, the mechanism is disproven for ~$0 — before any Hard attempt.

**Abandonment condition.** Abandon the skeleton if, after 10 Easy + 3 Medium runs with gate tuning: (a) G1 (per-digit 0.7) is never reached on E3, or (b) seen-N T=1 exact > 0.99 but OOD-N T=1 < 0.5 (meaning the comparator/table learned per-N shortcuts — the uniformity claim is empirically false), or (c) Medium M1 (depths {4,8,16}) certifies T=4 but fails T=1 — which would empirically confirm Theorem 1's ghost *inside* the (B1)+(B2) class and falsify Theorem 3's applicability to the trained (non-integral) network.

## 7. Ranked recommendations

1. **DRM (§4)**: canonical digit registers + learned table/carry/compare/subtract on structural convolution-and-shift routing + ST canonicalization + input-reconstruction anchor + gates G0–G3. It is the only proposal with a *proof* (Thm 3) that even-depth-only training identifies the T=1 step, and it is falsifiable in 60 seconds.
2. **Generic looped TRM over canonical registers**: same register manifold, ST rounding, reconstruction anchor and gates, but a weight-tied local-attention block replaces the explicit (M)(C)(R) wiring. Legally bulletproof and robust to "altered recurrence"; loses Theorem 3 (identifiability again rests on Occam bias), needs more of the 3600 s to discover routing.
3. **Binary-base DRM**: same as #1 with base-2⁵ limbs and carry-save accumulation — shorter registers, trivial comparator, faster reduce loop; strictly an engineering upgrade of #1 once #1 passes Easy.

**Bold alternative.** **Learned RNS-Montgomery machine**: represent the state by residues modulo ~16 learned-embedding small primes m_i (each channel a 6-bit one-hot); squaring becomes 16 *independent* 4096-entry learned tables (perfectly local, huge gradient signal, no carries); the entire difficulty migrates into a learned base-extension/comparison module for reduction mod the prompt-supplied N. High risk (base extension is the hard part, and canonical decoding back to decimal digits needs a learned CRT), but it converts the one part of DRM that is deep and sequential into the one part that is embarrassingly parallel — and nothing in the rules prefers positional base 10 except the output decoder.
